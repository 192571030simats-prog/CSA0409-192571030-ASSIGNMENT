# Task 5 – Distributed and cloud storage
NFS offers familiar shared-file semantics but depends on server/network availability. HDFS is optimized for large sequential data sets and commonly replicates blocks; Ceph provides distributed object, block and file interfaces. Cloud object storage scales elastically and integrates with CDN but uses object APIs rather than POSIX semantics. Replication improves availability/durability at storage and write-cost overhead. Strong consistency simplifies reads-after-writes; eventual consistency may expose stale results temporarily. Device path: application → filesystem → block layer → driver → controller/device; buffering, page cache and I/O scheduling reduce latency and improve throughput.
