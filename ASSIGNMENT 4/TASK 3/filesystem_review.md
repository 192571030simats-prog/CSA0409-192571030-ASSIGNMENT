# Task 3 – Modern file systems
FAT32: broad compatibility, 4 GiB minus 1 byte file limit, no journaling. NTFS: Windows default, journaling metadata, ACLs, compression and large volumes. ext4: Linux general-purpose journaling, mature tooling. XFS: high-throughput/scalable Linux journaling. Btrfs: copy-on-write, checksums, snapshots, subvolumes. ZFS: copy-on-write, end-to-end checksums, snapshots, RAID-Z and pooled storage. APFS: Apple copy-on-write metadata, snapshots, encryption and space sharing. Exact maxima depend on implementation and platform; verify against current vendor documentation before final submission.
